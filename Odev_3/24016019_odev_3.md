# Sınıflar Nesne yönelimli programlamanın temelini oluşturur(OOP). Anlaması biraz soyut olsa da mantığı oturtmak için bir örnek verirsek, classlar bizim çizdiğimiz bir kalıp gibi, daha sonra bu kalıptan kendi istediğimiz şekilde ürünler çıkartabiliyoruz. Sınıflar class anahtar kelimesi ile oluşturuluyor. içerisine yazdığımız init fonksiyonu ise ürün ilk oluşturulduğu anda otomatik çalışıyor ve özelliklerini anlatıyor. self kelimesi de o ürünün kendisini temsil ediyor, class içerisindeki ürünlere ulaşmak için başına "self." koymamız zorunlu.                      

ÖRNEK


class IHA:
    def __init__(self, ad, sinir_irtifa):
        self.ad = ad
        self.sinir_irtifa = sinir_irtifa
        self.suanki_irtifa = 0

    def yuksel(self, metre):
        if self.suanki_irtifa + metre <= self.sinir_irtifa:
            self.suanki_irtifa += metre
            print(self.ad, "yükseldi. Yeni irtifa:", self.suanki_irtifa)
        else:
            print("Uyarı! Maksimum irtifa sınırını geçemezsin.")
